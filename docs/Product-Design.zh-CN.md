## 1. 执行摘要

Relay 的核心主张：为每位员工提供一个长期 AI Partner，把员工从低价值事务性工作中释放出来，让更多时间回到客户价值、业务创新和组织能力建设。

Relay 不是简单聊天机器人、企业知识库或 Agent 开发平台。它围绕真实员工工作流持续学习、协作和执行。

| 维度 | 内容 |
| :-: | :-: |
| 一句话定义 | Relay 给每位员工一个 AI Partner，连接组织知识、业务流程和专业能力，让员工更快创造价值。 |
| 目标用户 | 销售、客户成功、产品经理、工程师、项目经理、顾问、培训团队和管理者。 |
| 核心价值 | 提升效率、增加知识复用、捕获专家经验、降低协作摩擦、增加客户价值创造。 |
| 初始场景 | 销售价值创造、产品与工程协作、客户成功运营、组织知识助手、专家经验捕获。 |
| 长期愿景 | 从 Personal Relay 发展到 Team Relay 和 Organization Relay，形成企业组织智能网络。 |

## 2. 背景与市场机会

企业数字化长期依赖员工在 CRM、ERP、OA、LMS、Wiki 等系统中录入、搜索和协调。AI Agent 第一次让系统中的信息具备可执行能力。员工不应再在多个系统间频繁切换，而应通过理解业务、具备权限边界、可以闭环推进任务的 AI Partner 工作。

企业购买 Relay，不是因为想要“Agent”，而是希望同样的人才能在同样时间内创造更多价值。

现有工具的空缺：

| 类型 | 能力 | 局限 | Relay 切入点 |
| :-: | :-: | :-: | :-: |
| 通用 LLM | 问答、写作、分析 | 缺少企业上下文、权限、长期记忆和闭环执行 | 围绕员工角色和场景构建长期 AI Partner |
| Copilot 类工具 | 办公软件内提效 | 偏文档/邮件/会议，跨系统执行弱 | 连接知识、工作流、工具和协作者 |
| 企业知识库/RAG | 查询文档和制度 | 多停留在回答，难推动工作 | 从“知道”升级到“执行与沉淀” |
| Agent 开发平台 | 工具调用和自动化流程 | 偏技术平台，业务用户难直接看到价值 | 用高频高 ROI 场景交付产品价值 |

核心痛点不是工具不足，而是高价值员工被查资料、写总结、发邮件、同步进度、追跟进、填系统、做报表等低价值事务消耗。

## 3. 产品定位

Relay = The AI Partner for Every Employee.

Relay 是企业 Workforce Intelligence Platform。它连接员工、组织知识、业务流程、内部系统和 AI Agent，形成 Human + AI 的新工作方式。

| 维度 | 内容 |
| :-: | :-: |
| Relay 不是什么 | 不是简单 AI 聊天机器人；不只是知识库；不是开发者中心的 Agent 平台；不是裁员工具。 |
| Relay 是什么 | 面向业务场景的员工 AI Partner，帮助员工完成工作、协调协作、沉淀经验、创造价值。 |
| 核心理念 | Every Employee. Amplified. |
| 企业收益 | 让同样的人才基础创造更多客户价值、业务价值和组织能力。 |

北极星指标包括高价值工作时间占比、任务完成率、知识复用率、协作摩擦降低、员工采用与信任。

## 5. 重点场景

### 5.1 销售价值创造助手

Relay 在会前汇总客户背景、历史沟通、合同、使用、风险和机会；会中提取需求、预算、决策链、异议和下一步；会后更新 CRM、生成跟进邮件、通知方案/产品/法务；长期追踪客户健康、竞品信号、续约风险和扩张机会。

价值：增加客户沟通时间、缩短新人 ramp-up、减少 CRM 缺失、沉淀高绩效销售打法。

### 5.2 产品与工程协作助手

Relay 聚合客户反馈、工单、会议和 IM 中的需求，生成 PRD 背景、用户故事、业务规则、验收标准和风险，连接 Jira/Git/CI/测试系统识别延期和质量风险，并从需求、提交和测试结果生成发布说明。

价值：让产品经理从文档行政回到用户洞察和产品创新，减少上下文丢失和重复争论。

### 5.3 客户成功与续约增长助手

Relay 结合产品使用、工单、会议频率、满意度和商务信息生成健康分，发现关键联系人离职、使用下降、投诉增加等风险，并给出续约与扩张建议，自动生成 QBR 草稿。

价值：提升续约率和客户生命周期价值，让客户成功从被动响应转向主动经营。

### 5.4 组织知识助手

Relay 连接文档、IM、邮件、CRM、项目管理和培训系统，不仅回答“文档怎么说”，也回答“当时为什么这样决策、谁做过、结果如何”，并把高频问题、关键决策和最佳实践沉淀为组织记忆。

### 5.5 专家经验捕获与能力复制

Relay 持续记录专家项目过程、沟通模式、决策理由和交付物，提取可复用模式、模板、案例和行动建议，帮助新员工获得专家级工作指导。

## 6. 产品能力体系

三种产品形态：

| 层级 | 目标 | 核心能力 | 价值 |
| :-: | :-: | :-: | :-: |
| Personal Relay | 每位员工 | 个人工作助手、知识助手、任务执行、个人记忆 | 提升个人效率和价值创造 |
| Team Relay | 团队/部门 | 团队状态、跨人协作、项目风险、最佳实践 | 提升团队协作效率 |
| Organization Relay | 企业/组织 | 组织知识、经验资产、能力图谱、治理分析 | 建立组织智能 |

核心模块包括 Relay Identity、Work Memory、Knowledge Connector、Task Orchestration、Tool and MCP Gateway、Sandbox Runtime、Human-in-the-loop、Analytics Dashboard。

执行边界必须区分：

| 动作类型 | 示例 | 策略 |
| :-: | :-: | :-: |
| 推荐 | 生成邮件、总结会议、分析客户风险 | 可直接生成，由员工确认使用 |
| 低风险执行 | 更新非关键字段、创建任务、整理材料 | 授权后可自动执行，并保留审计 |
| 高风险执行 | 正式报价、合同审批、删除数据、外部承诺 | 必须人工审批 |

## 7. 差异化策略

Relay 的差异化不在于 Agent 数量，而在于能否把员工工作、组织知识和价值创造连接成闭环。

| 维度 | 普通 AI 助手 | Agent 开发平台 | Relay |
| :-: | :-: | :-: | :-: |
| 起点 | 回答问题 | 构建自动化 Agent | 员工价值创造 |
| 用户 | 个人/办公用户 | 开发者/技术团队 | 业务员工、团队管理者、企业领导 |
| 结果 | 内容生成 | 工具调用 | 工作完成、知识沉淀、经验复用 |
| 上下文 | 短期对话 | 任务上下文 | 长期员工上下文 + 组织上下文 |
| 组织价值 | 有限 | 依赖开发能力 | 构建组织智能 |

品牌叙事应避免“替代员工”。Relay 是员工的工作伙伴、团队加速器和组织智能基础设施。

## 8. 商业价值与 ROI

Relay 的价值来自释放事务性时间，并将其中一部分转化为客户沟通、方案改进、产品创新和决策等高价值活动。

关键指标：高价值工作时间占比、任务完成率、销售转化/续约率、知识搜索时间下降、跨职能协作周期缩短、新员工 ramp-up 缩短、专家经验资产化数量。

## 9. 商业模式与采用路径

商业模式包括 SaaS Subscription、Enterprise Subscription、Scenario Packages、Private Deployment 和 Professional Services。

采用路径：

1. 不以“全员 Agent 平台”切入，而从高 ROI 场景开始。
2. 优先销售、客户成功、产品工程等核心价值链部门。
3. 用 6-8 周 PoC 证明效率、知识复用和业务指标提升。
4. 从单部门扩展到跨职能场景，再扩展到组织级智能。

## 10. 产品路线图

| 阶段 | 时间 | 目标 | 核心能力 |
| :-: | :-: | :-: | :-: |
| Phase 1: Personal Relay | 0-6 个月 | 让员工每天愿意使用 | IM 接入、知识检索、会议/文档助手、基础任务执行 |
| Phase 2: Scenario Relay | 6-12 个月 | 在核心业务场景证明 ROI | 销售、产品、客户成功场景包；CRM/Jira/文档连接器；审批机制 |
| Phase 3: Team Relay | 12-18 个月 | 从个人助手升级为团队协作智能 | 团队状态、项目风险、跨 Agent 协作、管理看板 |
| Phase 4: Organization Relay | 18-36 个月 | 建立组织智能网络 | 组织记忆、专家经验库、能力图谱、治理与审计 |

## 11. 风险、边界与治理

| 风险 | 表现 | 治理策略 |
| :-: | :-: | :-: |
| 员工抵触 | 担心替代或监控 | 强调员工放大，提供数据透明和员工可控授权 |
| 权限风险 | Agent 误操作或越权 | 员工权限、Agent 权限、任务权限和审计轨迹 |
| 幻觉与错误 | 信息或建议错误 | 关键任务要求来源、置信度和人工确认 |
| 数据安全 | 敏感数据泄露 | 租户隔离、私有化部署、脱敏、访问控制 |
| 工具执行风险 | 外发、审批、删除等高风险动作 | Human-in-the-loop 和审批策略 |
| 价值不可见 | 客户看不到节省和创造的价值 | 内置 ROI 看板和场景指标 |

## 12. 结论

Relay 的机会不是再做一个 Agent 平台，而是重新定义 AI 时代员工和组织的工作方式。它应从高价值、高频、可衡量的业务场景切入，先帮助销售、产品、客户成功、工程和专业服务团队提升价值创造，再逐步演进为企业组织智能基础设施。
