Relay · design tokens · specimen

Phosphor

Relay is grey until something is working. True-neutral canvas · monochrome white/black action · status as a grey brightness hierarchy — dots, borders, text, never fills · one chromatic role, --live, reserved for an agent working right now. Two registers, designed side by side.

Action — white on dark, black on light

The entire action family: rest, hover, selection wash, and the text that sits on the fill. Pure monochrome, Linear-style — no chroma anywhere. No disabled hex — disabled is opacity. On dark the fill is white, so on-action text is dark ink; on light it is black and carries white.

--on-action#101214#fffffftext on the action fill

Status — dots, borders, text. Never fills.

A grey brightness hierarchy — loud = bright (--err brightest), calm = dim (--ok dimmest); the dot color and the text color are the same token. Warn and err pass AA as small text; ok is the decorative-calm tier. Info is not a color; it aliases --ink-3.

TokenDarkLightRole
--ok#7d848d#6b727bready, passed, done — calm (dim)
--warn#99a0a8#5c636battention, degraded
--err#f2f4f6#16181bfailed, destructive — loud (bright)
--info= --ink-3= --ink-3neutral notice
--live#3ee08a#0b7a45an agent is working right now — the only hue

--live is scoped, not decorative. It is legal exactly where --t-pulse is used (streaming agent, running task, busy header) and never where --t-pulse-calm is (online dot, idle node). Login is monochrome — it reports readiness before auth, not agent work. It never means success or "done": a finished task is grey. Both register values pass AA as small text (10.94:1 dark, 5.08:1 light); #0f8a4e is the tempting lighter green and fails at 4.14:1.

02 · Typography

Two families, ten roles

JetBrains Mono carries the display tier and technical text; Geist carries reading and control text. Display and code share a face, so they are separated by weight, tracking, and colour — 700/600 in --ink-1 with --track-display for titles, names, and metrics; 400 untracked in --ink-4 for IDs, logs, and code. That gap is what stops an agent name and a session ID reading as the same kind of object. (This demo falls back to your system mono and sans if the families aren't installed locally.)
