Precision control plane

Orchestrate agents with monochrome precision.

A preview of the Relay design language: white canvas, near-black ink as the only action color, Geist Mono as the identity signal, tight geometry, and color reserved strictly for status. In the Linear / Vercel / Resend lineage.

Monochrome action, color for status.

Ink carries every action and inverts to white-on-black in dark mode. The only hues on screen are status — success, danger, warning, info.
